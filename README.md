# Benign by Script — audit code and results for the 5G-NIDD paper

Reproduction package for the manuscript *"Benign by Script: A Large-Scale
Labelling Error and Identity Shortcuts Behind 99.9% Results on the 5G-NIDD
Intrusion Dataset"*.

**This repository contains no dataset.** 5G-NIDD is distributed by its authors;
see [DATA.md](DATA.md) for how to obtain it. Nothing here redistributes network
traces, and the result files included are summaries (JSON/CSV/LaTeX), never raw
flows.

> **Keep this repository PRIVATE until the paper is submitted.** It contains an
> `internal/` folder with reviewer-risk notes, a rigour verdict and an unsent
> draft email to the dataset authors. Use `make_public_release.sh` to produce a
> copy without `internal/` when you are ready to publish.

## What the paper claims, and where to check it

| claim | check it here |
|---|---|
| 281,529 UDP flood flows are labelled Benign in the BS1 capture (23.15% of the dataset, 58.93% of its Benign class) | `results/study_5gnidd_audit/e1_config.json`, `e1_counts.csv` |
| The labels follow a (capture session x source IP) rule, reproduced exactly by a depth-2 tree | `src/audit/` (e3), `results/pilot_audit/` |
| 281,505 of those rows have record-level twins labelled UDPFlood in the other base station | `results/pilot_audit/c5_task1.json` |
| Seq and Offset act as identity shortcuts (permutation accuracy drop 0.3012) | `results/study_5gnidd_audit/e4_perm.json`, `e4_runs.csv` |
| 11 models score 0.9724-0.9996 accuracy against the original labels, 0.7422-0.7681 against corrected ones | `results/study_5gnidd_audit/e2_summary.csv`, `results/study_5gnidd_dl/runs.csv` |
| Corrected versions restore honest evaluation (TPR 0.3245 -> 1.0000 training on BS1; FPR 0.6918 -> 0.0001 training on BS2) | `results/study_5gnidd_audit/e2_summary.csv` |
| In-capture audits miss the error; cross-capture disagreement finds it, but the pre-set F1 gate was not met | `results/study_5gnidd_audit/e5_runs.csv`, `e8_*`, `e9_*` |
| Using a cross-partition audit as an automatic corrector also fails its pre-registered gate | `preregistration/`, `results/study_cpla/` |

## Layout

```
src/            analysis code (audit, deep-learning, pilots, paper build)
results/        summary outputs only: JSON, CSV, LaTeX tables, NUMBERS.json
figures/        figures used in the paper (PDF)
paper/          main_v10.tex, references.bib, tables/, figures/
preregistration/ frozen corrector-study script, its docstring and hash
internal/       NOT for publication: risk notes, rigour verdict, email draft
```

## The number manifest

Every number in the manuscript is extracted programmatically into
`results/NUMBERS.json` (2,626 entries). Each entry records `value`, the source
`file`, and `where` (the column or field it came from). `src/paper/check_numbers.py`
re-reads the manuscript and every LaTeX table and fails if any number cannot be
matched to an entry.

Known limitation (documented, not fixed): the checker verifies that a number
*exists* in the manifest, not that the *right* entry backs the claim. See
`internal/NUMBER_RECONCILIATION.md` section 3.

## Quick start

```bash
pip install -r requirements.txt
# 1. obtain 5G-NIDD yourself (DATA.md), then:
python src/audit/make_clean.py          # builds versions A / B / C
python src/paper/make_all.py            # NUMBERS.json -> tables -> figures -> checks
```

## Manuscript sources

`paper/` holds the v11.1 LaTeX sources: `main_v11_1.tex` (one column),
`main_v11_1_2col.tex` (two columns, generated by `make_2col_v11_1.py`),
`references.bib` (39 verified entries), `tables/` and `figures/`.
Compiled PDFs are **not** committed, because they are built from a copy that
carries the author's real contact address; the tracked sources use
`\ead{[corresponding author email]}` instead. Build instructions are in
[REPRODUCE.md](REPRODUCE.md) section 8.

Supporting evidence lives in `docs/`: `SUPPLEMENT_S1.md` (how references were
verified and how the prior-art search was run), `REFERENCE_AUDIT.md`,
`RELATED_WORK_EVIDENCE.csv`, `positioning_matrix_v11.csv` and
`EVIDENCE_gaps.md` (works deliberately left out of the comparison table).
